An evolving biomedical research project

From molecules to cell states.

Mora-3 studies how one model could link molecular design to measurable outcomes in cells and tissues. It brings structures, assays, gene expression, and images into a shared graph so evidence can travel in both directions.

Compatible native code. A complete registered-view group audit.

Flow proposals and FoT refinement

Generate several forests, refine them, retain multiple outputs.

The implemented inference controller batches whole-forest flow proposals, uses content-bound scores and constraint checks, replaces deficient subtrees without erasing their predecessors, and rechecks decoded outputs. It returns several distinct qualifying outputs or an explicit shortfall. This is not a claim of a trained or fully qualified native flow head.

Explore the interactive candidate and edit lineage

Source basis: Bi et al., Forest-of-Thought, ICML2025, sections3.1–3.3. Explicit latent subtree replacement and multi-output selection extend the paper rather than reproduce an undocumented edit taxonomy.

Native training integration · 13 November 2026

Four source-bound objectives. One checkpointed engine.

The implemented joint path combines whole-forest flow matching, source-aligned token reconstruction, criterion scoring and supported analogical pairs. Complete preflight preserves unknown labels, fixed observations and exact source roles before neural evaluation. Its finite source segment and random generator are bound to the native checkpoint.

Known skeletons only. This is implementation integration, not a claim that the full training corpus is ready or that a sweep has run. Unknown-topology learning, final source/model qualification and the 24-trial sweep and two target runs remain unfinished.

Normalized forest topology and complete methods

The native forest path now includes a bounded, normalized prefix policy for generating variable-size ordered trees before continuous latent flow. Source-aligned topology supervision is bound through the native objective, route, owner and checkpoint interfaces. This is an implementation, not a trained-quality result.

The complete methods manuscript includes twelve scoped propositions and theorems with proofs, six interactive diagrams, construction and training details, and deliberately empty empirical tables and charts.
