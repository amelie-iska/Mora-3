01 · A biological record

A typed record links molecules, sequences, structures, images, expression and assay context only where sources support the link. A task mask selects known fields and requested outputs. Missing or censored measurements keep their own status.

Scoped implementation. Native readers and target exclusion have scoped checks. Complete source eligibility, split integrity and shared coverage remain open.

02 · TokenGT graph encoding

Each node and directed edge becomes its own token. Orthogonal endpoint identifiers preserve who connects to whom. Role, type and payload embeddings carry information for the shared transformer.

Scoped implementation. The graph and payload path has bounded integration evidence. A hidden target can still leak through topology, so known- and unknown-topology tasks need separate tests.

03 · ConvexTok vocabulary

ConvexTok selects a vocabulary using a linear relaxation and rounding. Encoding then uses a shortest path through eligible pieces. Exact byte fallback preserves any content that the vocabulary does not cover.

Scoped implementation. A bounded reference fit and round-trip were checked. Fit learned vocabulary only on eligible training groups.

04 · Tropical attention

For a query and key in the finite reference core, the score is the negative range of their coordinate differences. For each output coordinate, take the maximum of score plus value across valid keys. The operator uses no softmax.

Scoped implementation. Dense and tiled first-order reference checks exist. The finite code wrapper and paper valuation differ. Ring execution and extreme context remain unqualified.

05 · Learned concept directions

GraphCG learns directions in an existing generator’s latent space. Mora-3 studies a direction set as a possible concept basis. Steering adds a scaled direction to a point, then checks whether decoded properties change consistently and independently.

Reference diagnostic. A linear editor and contrastive loss were tested. The fixed-pair diagnostic worsened. Useful semantic control, independent factors and a complete basis remain unproven.

06 · Continuous latent GFlowNet

A trajectory samples continuous latent states across time layers. A forward policy proposes moves and termination, and a backward policy scores the reverse moves. Trajectory balance compares the two against a declared positive terminal reward density.

Scoped implementation. Density, stop and trajectory balance components have scoped tests. A diagnostic reward does not establish a useful biological sampling distribution.

07 · Forest of Thought

Multiple latent trees can explore distinct candidate trajectories under the same conditions. A bounded selection rule keeps eligible, high-scoring branches. An optional distance guard can reject nearby states under a declared metric.

Reference diagnostic. Selection and per-tree provenance are implemented in bounded tests. Diversity and biological reasoning quality require separate evidence. Inference selection changes the training proposal distribution.

08 · Analogy in embedding space

Compare how a source pair changes in a shared representation, then retrieve or propose a target change under matching constraints. The plan considers graph topology descriptors alongside latent geometry. A matching vector suggests an analogy whose meaning needs independent evidence.

Research plan. The diagram uses a vector translation as an illustration. Evidence for semantic, causal or biological transfer remains open.

09 · Multimodal output heads

Output heads follow the target modality. The design uses flow matching for suitable continuous coordinates or arrays and conditional autoregression for discrete sequences. Other tasks request expression, segmentation, phenotypes or assay-specific uncertainty.

Scoped implementation. Geometry components have scoped checks. Full structure, transition-state and enzyme workflows still need independent quality, validity, and export checks.

10 · Ensembles and dynamics

For a fixed molecular system, the proposed coordinate sampler targets an ensemble based on energy, temperature, constraints and reference measure. A latent or Cartesian generation path indexes sampler steps. Physical dynamics require a separate integrator with explicit time and force provenance.

Research plan. Ensemble coverage, reweighting, physical trajectory validity and kinetics remain open. The two-state example assumes equal base weights.

11 · Frozen UMA and eSEN teachers

A frozen interatomic potential can provide computed energy and forces for a declared domain. The proposed student uses these signals within a separate coordinate objective. Teacher identity, reference energy, topology and units are part of each target.

Staged research. Bounded UMA numerical and checkpoint checks are staged. An eSEN path and substantive teacher/student training are unqualified. Keep computed feedback separate from experimental measurements.

12 · Training and μP transfer

Qualify eligible data and the shared model, then profile and run the proposed proxy grid. Select settings on validation, freeze them for width transfer and reserve held-out tests for final evaluation. Full training is a separate stage.

Campaign gated. The published snapshot records zero of 24 planned primary starts. Diagnostics and proposed proxy and target counts are separate from trained results.
