## Complete-forest velocity and analogy

The actual learned velocity head reuses the registered GeometryConditioner and literal native TokenGT feature/layer/normalization modules. It processes direct continuous tensors for every node, directed parent-child edges, solver time and available biological context. Its context encoder currently uses the existing geometry bridge's ByteTokenizer; sharing transformer weights does not change that bridge into the separate learned annotation tokenizer. Unknown clean target fields are excluded. Free template coordinates cannot enter sampling. Joint noisy branches are valid denoising inputs, but this is not an autoregressive clean-prefix causal policy.

The analogy head learns a condition-only query and a complete-forest memory key. All nodes contribute once, including shared ancestors. A key is a lossy retrieval summary, not a semantic or directed proof. The contrastive objective uses explicit supported positive/negative masks; unknown correspondences are omitted. Source groups and original splits are checked. A deterministic farthest-pivot partition provides optional approximate L2 search, while exact search/all-cell probing supplies the reference. Frozen index identities bind actual weights, coordinates, source memory and grouping policy. Final directed/physical correspondence validation remains a separate requirement.

## Token vocabulary and decoder design

Implement a new explicit forest token axis derived from the existing AnnotationVocabulary. Keep its ordered256 byte tokens, learned payload strings and existing control IDs. Append the40 previously specified MORA controls in a fixed order. Preserve the original fit certificate as a base certificate and record the extended axis separately; do not claim a new ConvexTok LP fit. The extension is constructed explicitly, never silently applied to an old tokenizer/checkpoint. Existing payload metadata offsets and embedding rows are not mutated in place.

The first native decoder maps complete-forest hidden node states plus learned finite token-slot positions to a **fixed source-bound token-embedding codebook**. The codebook is supplied as an explicit immutable export with exact vocabulary/source/encoder/coordinate identity, rather than invented from a current untrained model. A learned projection supplies token-embedding coordinates. Negative squared Euclidean distance gives differentiable token scores; inference chooses the nearest permitted token. This realizes the user's rounding/refinement request without pretending a pooled latent is already an invertible token sequence. Finite codebook dimension is independent of muP width. Fixed codebooks are a conservative initial alignment choice, not a claim of superiority over jointly learned embeddings; Diffusion-LM(2205.14217) studies joint embeddings and rounding in a different text model.

Node content allows payload tokens and NODE_END as a learned stopping symbol. Source-known topology, parent references, evidence role and direction are serialized by a deterministic typed grammar, not silently predicted from hidden target structure. Every generated node has a content sequence; a missing stop within its finite slots is a censored/refused output, not forced completion. Fixed/clamped node contents must be explicitly source-bound or conservatively refused. The decoder preserves known clamped conditions and cannot relabel model-generated content as observed evidence. Forty controls remain available in the versioned axis even where a particular grammar uses only a subset.

Decoder training requires genuinely source-aligned complete forests and token targets. Masks retain unknown/truncated nodes instead of converting them into empty strings. The codebook and tokenizer identities, vocabulary size, slot count and source/coordinate versions are frozen before a campaign. Teacher-forced supervision and codebook targets never enter the forward context. Grammar-aware negative-log-likelihood and optional exact embedding-regression diagnostics are distinct objectives; no likelihood is assigned to the upstream deterministic flow from these token scores.

## Native score-directed subtree regeneration

Replace the previously supplied analytic edit callback with a concrete editor using the bound native velocity head. The editor selects a low-scored eligible subtree, draws independent noise only for its nodes, integrates the actual full-forest field while fixing all other candidate nodes, and returns fresh revisions. Preserved generated branches are explicitly proposal context, not reclassified as observed conditions. Original conditions and sibling values remain unchanged, and every new subtree requires fresh whole-forest/decoded verification. The editor preserves explicit RNG state and reports real field evaluations. It makes no guarantee of improvement, no biological-validity claim and no on-policy GFlowNet claim. A stale model, invalid assessment or unsupported shape must refuse before consuming the generator.
