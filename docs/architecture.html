Representation

Keep the graph and the measurement.

Each node or directed edge has its own token. Orthogonal endpoint identifiers and role/type embeddings preserve incidence and direction. Continuous measurements retain native units and assay context; sequences and text retain reversible tokenization.

A task must withhold target values and any metadata, topology, or identifier that would reveal them. Known-topology prediction and unknown-topology generation are separate tasks.

Efficiency

Long context is an experiment.

The plan compares exact blockwise operators, compatible custom kernels, and cache compression where applicable. Training memory, cached inference, held-out quality, and actual end-to-end throughput must be measured separately on representative multimodal records.

The single-GPU path does not establish distributed scaling or extreme-context full-model training.
