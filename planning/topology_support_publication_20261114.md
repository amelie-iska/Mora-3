# Reachable topology support and immediate source publication

The latest user instruction authorizes non-destructive publication at tested
progress checkpoints independently of training start. No change is made to the
complete eligible dataset, native owner, run-budget or source rights requirements.

A native topology sampler currently checks only the current prefix against its
attention budget. A normalized abstract grammar can therefore assign positive
mass to a continuation which exceeds that runtime budget. Reject the entire
unsupported grammar before the first neural call or random draw rather than
silently conditioning on successful samples or shrinking the frozen support.
Compute its exact attainable maximum node count from the fixed roots, depth,
child cap and total node cap. Depth-zero/child-zero supports must retain their
smaller exact maximum instead of being incorrectly refused by a loose M bound.
Record the new complete-support policy in a versioned native checkpoint config.

Write meaningful failing tests, independently enumerate small grammars and
compare maxima, test unsupported sampling before neural/RNG effects, and retain
supported limited-depth/multiple-root laws. No optimizer updates, campaign runs,
packages or data mutations. Review and preserve the already completed topology
implementation and methods-paper artifacts instead of recreating them.

Update current manuscript/publication guidance for the new user instruction,
retain historical receipts unchanged, refresh primary-reference metadata, rebuild
and inspect the PDF/live diagrams with empirical results still unpopulated.
