01 · A biological record

A typed record links molecules, sequences, structures, images, expression and assay context only where sources support the link. A task mask selects known fields and requested outputs. Missing or censored measurements keep their own status.

Scoped implementation. Native readers and target exclusion have scoped checks. Complete source eligibility, split integrity and shared coverage remain open.

Observed payloads + availability/status masks → nodes, directed edges and condition selectors.

Only supplied incidence is visible. Unknown target connectivity cannot become an input.

02 · TokenGT graph encoding

Each node and directed edge gets a token. The encoder adds a feature projection, a projection of the two ordered endpoint IDs, and a learned node or edge role. It prepends a separate learned graph token.

Scoped implementation. The graph and payload path has bounded integration evidence. A hidden target can still leak through topology, so known- and unknown-topology tasks need separate tests.

Features [N+E,F], endpoint pairs [N+E,2], roles [N+E] and node IDs [N,d_id] produce [N+E,d]. Add the graph token and pad graphs to obtain [B,L,d] with a validity mask [B,L].

Node endpoints repeat the same ID. Edge endpoints preserve source then destination. Graph incidence is carried in the token features, distinct from the padding mask used by attention.

03 · ConvexTok vocabulary

ConvexTok selects a vocabulary using a linear relaxation and rounding. Encoding then uses a shortest path through eligible pieces. Exact byte fallback preserves any content that the vocabulary does not cover.

Scoped implementation. A bounded reference fit and round-trip were checked. Fit learned vocabulary only on eligible training groups.

A path over byte offsets selects vocabulary pieces and represents every byte. Token embeddings are a later step.

Fit the vocabulary on eligible training groups. The browser uses a fixed four-piece vocabulary and a unit cost per piece.

04 · Tropical attention

For a query and key in the finite core, the score is the negative range of their coordinate differences. Each output channel takes the maximum of score plus that key’s value across valid keys.

Scoped implementation. Full and blockwise reference reductions have scoped checks. The code wrapper uses ReLU followed by log1p, shared head-local max-plus projections, expm1, and a bias-free output projection. Distributed execution and extreme context remain research goals.

The core accepts Q [B,H,Lq,d_h], K [B,H,Lk,d_h], V [B,H,Lk,d_v] and key validity [B,Lk]. Scores [B,H,Lq,Lk] reduce to output [B,H,Lq,d_v].

For each valid key, score=min(Q−K)−max(Q−K). Each output channel independently takes maxₖ(score+Vₖⱼ) without softmax. The scene starts after projection, with one query and all three toy keys valid.

05 · Learned concept directions

GraphCG learns directions in an existing generator’s latent space. Mora-3 studies a direction set as a possible concept basis. Steering adds a scaled direction to a point, then checks whether decoded properties change consistently and independently.

Reference diagnostic. A linear editor and contrastive loss were tested. The fixed-pair diagnostic worsened. Useful semantic control, independent factors and a complete basis remain unproven.

z [d] + α direction [d] → z′ [d]; decode using the same conditional head.

Direction length is computed; semantic identity, disentanglement and independence are not established by it.

06 · Continuous latent GFlowNet

A trajectory samples continuous latent states across time layers. A forward policy proposes moves and termination, and a backward policy scores the reverse moves. Trajectory balance compares the two against a declared positive terminal reward density.

Scoped implementation. Density, stop and trajectory balance components have scoped tests. Matching a target terminal reward distribution requires balance and a valid target measure.

Forward and backward log densities [B,T] and a prefix mask [B,T] combine with scalar log Z, terminal log stop [B], and log reward [B] to give residuals [B]. The loss is their mean square.

Forward entries already include eligible continuation log mass. The backward origin entry is zero and terminal stop appears once. Generative step indexes count sampler moves.

07 · Forest of Thought

Multiple latent trees can explore distinct candidate trajectories under the same conditions. Each tree keeps eligible branches by layer score and can use a Euclidean distance guard to reject nearby states.

Reference diagnostic. Selection and per-tree provenance are implemented in bounded tests. Search is an inference operation. Feeding selected paths back into training would change the training proposal distribution.

Per-tree candidate states, scores, ancestry and optional metric distances → bounded selected indices.

Retain tree identity; global top-K is not interchangeable with per-tree top-K. Selection changes proposal density.

08 · Analogy in embedding space

Match a typed source motif (ligand → receptor → response) to a target motif before transferring a displacement. The shared representation proposes a neighborhood; role, directed incidence, fixed-context and assay constraints filter candidates independently. A close embedding cannot rescue reversed topology or a changed endpoint. This is a synthetic relation template, not a causal biological claim.

Research plan. Typed motifs, distances and refusal rules below are computed educational fixtures, not learned retrieval scores. Shared encoders exist; a qualified analogy retrieval/transfer route and biological validation remain open.

Two role-aligned source states give Δz. Query z_target+λΔz ranks candidates by −||z_candidate−query||².

Require role and directed-edge correspondence, fixed context, same endpoint and source eligibility before ranking.

Audit full-space analogue retrieval

09 · Multimodal output heads

Output heads follow the target modality. The design uses flow matching for suitable continuous coordinates or arrays and conditional autoregression for discrete sequences. Other tasks request expression, segmentation, phenotypes or assay-specific uncertainty.

Scoped implementation. Geometry components have scoped checks. Full structure, transition-state and enzyme workflows still need independent quality, validity, and export checks.

Coordinate head [atoms,3]; sequence head [steps,vocab]; raster head [H,W,channels]. Each head has its own target axes.

The synthetic interpolation preserves atom IDs in a fixed frame. Chemical validity requires a separate check.

10 · Ensembles and dynamics

For a fixed molecular system, the proposed coordinate sampler targets an ensemble based on energy, temperature, constraints and reference measure. A latent or Cartesian generation path indexes sampler steps. Physical dynamics require a separate integrator with explicit time and force provenance.

Research plan. Ensemble coverage, reweighting, physical trajectory validity and kinetics remain open. The two-state example assumes equal base weights.

Fixed system, energy reference and positive temperature define log reward; sampling and physical integration are separate.

The two-state partition assumes equal base weights. A sampling path does not supply kinetic rates or physical elapsed time.

11 · Frozen UMA and eSEN teachers

A frozen interatomic potential can provide computed energy and forces for a declared domain. The proposed student uses these signals within a separate coordinate objective. Teacher identity, reference energy, topology and units are part of each target.

Staged research. Bounded UMA numerical and checkpoint checks are staged. An eSEN path and substantive teacher/student training are unqualified. Keep computed feedback separate from experimental measurements.

A request pins the atom order, coordinate frame [N,3], applicable system metadata and teacher. Computed results can carry a scalar energy and forces [N,3].

Same-geometry complex/fragment subtraction needs complete matched references. Electronic interaction and experimental affinity have separate targets.

12 · Training and μP transfer

Qualify eligible data and the shared model, then profile and run the proposed proxy grid. Select settings on validation, freeze them for width transfer and reserve held-out tests for final evaluation. Full training is a separate stage.

Campaign gated. The published snapshot records zero of 24 planned primary starts. Diagnostics and proposed proxy and target counts are separate from trained results.

Exact source/task axes, updates, optimizer roles, seeds and metric coordinates → separately pinned trial receipts.

μP parameter-role transfer is not trained quality evidence. Heldout tests cannot select hyperparameters.
