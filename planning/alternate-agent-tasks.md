# Mora-3 alternate-agent tasks

Start from [the integrated qualification packages](../docs/alternate_agent/README.md).
Use an isolated worktree based on current `main`. Keep released source roles,
original data, and active experiment state immutable. Use the existing project
environment and submit code, tests, and sanitized receipts for each package.
The coordinator owns the common source snapshot, GPU scheduling, and launch.

## 1. Close GRH overlap and native intake

- Extend the coordinator's verified train conflicts into complete
  connected identity components. Include validated molecule and scaffold keys,
  original source groups, and released conformer and trajectory lineage. Preserve
  original roles and report candidate exclusions by route and reason.
- Verify the reach of the static GRH validation conflicts against the
  current protected test cohort. Resolve all descendants and bridges using
  frozen group metadata. Report expected and observed counts, including zero
  intersections after applying a candidate mask.
- Bind eligible native GRH objectives to original evidence, rights, units,
  missingness, and explicit denominators. Submit an inactive reader and
  independently replayable mask witness.

## 2. Qualify SCRI, tasmorpho, and BETSEE

- Profile the integrated spatial owner on realistic graph sizes and paired
  modalities. Verify identifier orthogonality, missingness, target masking,
  gradients, and recovery at the registered widths. Record resource ceilings
  and failures alongside successful results.
- Reproduce one pinned tasmorpho or BETSEE simulation from the original inputs
  in a fresh output directory. Bind versions, seeds, solver tolerances, run
  rights, and raw-to-curated lineage. Keep whole simulation lineages together.
- Keep simulator outputs, imputed values, and experimental outcomes in separate
  evidence classes. Preserve intervention target, action, time, control, and
  units in native gap-junction and ion-channel records.

## 3. Close unassigned expanded-source gaps

- Reconcile transition-state enzyme design, X-Pert, MINT, and both small-molecule
  and peptide retrosynthesis with the current source and route witnesses. Report
  original and eligible denominators, every exclusion reason, rights, groups,
  native objective coverage, and reproducible artifact digests.
- Coordinate before working on ProCyon, scCello, LINCS, ADMET, ReactZyme, and
  UMA/eSEN. Reuse verified artifacts and the current common source commitment.

## 4. Complete the standard-parameterization comparison

- Reuse the passing width-24 native μP CPU recovery receipt as a scoped control.
  Establish separate standard-parameterization optimizer and recovery evidence,
  then compare fixed-cohort coordinates across the registered widths.
- Freeze the baseline specs, seeds, metrics, transfer selection rule, and
  reporting contracts for 24 primary, 8 baseline, 9 transfer, and 3 naive target
  trials. Keep optimizer updates, model qualification, and actual trial starts
  separately accounted for.
- Coordinate device testing with the launch owner. Include full-head parameter
  and alias counts, measured RTX 4090 memory and throughput, and recovery results
  against the same source and model snapshot.

## Handoff

For each package, supply the commit or patch, exact evidence digests,
completed/required counts, focused test results, and the next actionable gate.
Keep protected coordinates, restricted payloads, credentials, and private
planning records out of the patch.
