# Flow-forest research explorer

Open `flow-forest.html` in a JavaScript-enabled browser. It is self-contained and needs no package install, server, account, model or network access. If a managed browser forbids local-file navigation, use an existing approved local preview facility; do not change browser security or install software merely to view it.

The seven views are architecture, complete-forest interpolation, directed analogy and persistence, typed decoding, few-step flow maps, contextual quality/adapters, and campaign/evidence boundaries. Sliders, the supplied-square switch, modality/evidence selectors, token search, keyboard tab navigation, hash state, SVG export and JSON state export are functional. Narrow screens retain readable intrinsic diagrams with horizontal panning and text explanations below. There is no animation, telemetry or automatic external request.

All numerical demonstrations are deterministic mathematical fixtures. The explorer does not run Mora-3, train a neural network or certify biological quality. Existing/proposed/budget-blocked component status is explicit. Static vector figures for the paper are generated by the identical renderer, with no invented empirical plots.

Rebuild from repository root:

```bash
python3 tools/build_flow_forest_page.py
node tools/export_flow_forest_figures.cjs
node --test tests/project/flow-forest-math.test.cjs
```

Browser QA uses an already installed Chromium and Playwright:

```bash
CHROMIUM_PATH=/path/to/existing/chromium python tests/project/test_flow_forest_browser.py
```

The browser test skips explicitly if Chromium is unavailable and never downloads it. The delivered QA used an isolated tool-container Chromium, not the user's logged-in browser. A first attempt to navigate by `file://` was blocked by that test browser's administrator policy; the successful tests load the exact self-contained HTML via `set_content` and exercise its real DOM/JS without external traffic. This workaround does not change browser security settings.

This companion is integrated into the GitHub Pages project home, live paper and training page. The earlier ChatGPT-hosted site is not controlled by this repository. Public source and mathematical illustrations remain distinct from private datasets, checkpoints and unverified training claims.

SVG geometry attributes are serialized to nine decimal places for reproducible Node/Chromium exports. This affects display coordinates only (at most 5e-10 viewBox units), not equations, numeric analysis results or source values.


## Flow proposal and refinement replay

`flow-fot-refinement.html` runs an offline interactive replay generated by the actual
Python inference controller on a synthetic analytic fixture. It preserves all
initial candidates and correction lineage; selecting an iteration or candidate
changes the rendered full forest and exact stored scores. Three separately checked
outputs are retained. The paper SVG is exported from the same renderer.

Build with `PYTHONPATH=src python tools/build_flow_fot_refinement_example.py`, then
`python tools/build_flow_fot_refinement_page.py`. Existing Chrome/Playwright can run
`python tests/project/test_flow_fot_refinement_browser.py`; no installer is invoked.
The native trained velocity/decoder integration remains unqualified. This is not a
source-admission receipt or a trained reasoning-quality demonstration.


## Native neural-head diagnostic — 13 November 2026

Open `native-forest-heads.html` for retained computations from the actual optional
velocity, analogy, decoder and criterion-scoring modules. All weights are randomly
initialized and all inputs/codebooks are explicit software fixtures. Condition/time
controls show native velocities; node/slot controls show full3D nearest-token
distances. Criterion values and exact/approximate memory results remain visible.
No training, semantic accuracy or biological result is implied.

Build with `tools/build_native_forest_flow_example.py` using the existing project
environment, then `tools/build_native_forest_head_page.py`. Browser checks are in
`tests/project/test_native_forest_heads_browser.py`; they require an already installed
Chrome/Playwright and never install anything. The corresponding paper SVGs are
exported from this page's actual renderer.
