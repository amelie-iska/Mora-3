What is exact—and what is not

λₖ(t) = k-th largest max(0, min(t − birthᵢ, deathᵢ − t))

A complete landscape retains the finite persistence diagram, up to the usual zero-length interval convention. On every segment between all endpoints, peaks and active tent crossings, each landscape is linear. Two-point Gauss integration therefore gives the exact L2 integral in real arithmetic. The implementation uses float64; it does not claim symbolic or bit-perfect real arithmetic.

Preservation contract

Native barcodes remain stored with multiplicities, birth/death simplices, coefficients and essential/censored status. Exact memory ranking compares finite landscapes only when the essential birth multisets agree. Incomplete and right-censored filtrations cannot masquerade as completed evidence. This is lossless retention of the existing persistence record, not reconstruction of every original geometric or directed property from homology.

Fast sampled landscapes and persistence images

Sampled landscapes use square-root quadrature weights before Euclidean comparison. Persistence images use Gaussian rectangle integrals, not samples at pixel centers. Pixel-mass L2 and piecewise-constant image-density L2 are distinct and named explicitly. Finite grids, rank truncation, smoothing and image boundaries can lose information. These outputs never replace the original diagrams.

Native analogy and tropical attention

The native topology-memory retrieval path uses batched complete-landscape L2 by default, scores every eligible training memory, excludes held-out/shared-group records, and keeps the old bottleneck path explicitly selectable. Structural acceptance still checks the supplied directed presentation and the original complete-diagram tolerance; no bottleneck threshold is silently reinterpreted as L2. Landscape tents and order statistics use max/min piecewise-linear operations, but this does not establish equivalence to Mora-3 tropical attention or qualify a new operator for μTransfer.

Evaluation boundary

These are finite H1 mathematical fixtures. No protein, cell or reasoning-quality result is shown. The page tests numerical representations, not learned usefulness or full-campaign readiness.
